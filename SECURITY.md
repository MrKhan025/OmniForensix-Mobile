# Security & Forensic Integrity Policy

## Scope & Ethical Use

`OmniForensix-Mobile` is strictly a defensive, post-acquisition digital forensics and artifact analysis framework. Pull requests introducing device exploits, lockscreen bypasses, or unauthorized access payloads will be rejected.

## Reporting a Vulnerability

If you discover a security vulnerability (such as an archive traversal bypass, parser crash, or SQLite handling flaw), please open a private security advisory on GitHub rather than posting a public exploit.
